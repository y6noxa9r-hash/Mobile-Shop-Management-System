# Task 8 – Questionnaire
## Mobile Shop Management System

**Project:** Mobile Shop Management System  
**Task:** Prepare a questionnaire with at least two screens/pages containing questions and answers  
**Target participants:** Shop owners, sales employees, cashiers, inventory employees, and customers  
**Document status:** Questionnaire draft with sample answers for demonstration. Collect real responses before presenting the sample answers as survey results.

---

## Screen 1 – Current Shop Operations

**Purpose:** Identify the problems in the current process and understand how products and sales are managed.

### Q1. What is your role in the shop?
- [ ] Owner / Manager
- [ ] Sales Employee
- [ ] Cashier
- [ ] Inventory Employee
- [ ] Customer

**Sample answer:** Sales Employee

### Q2. How are product details and quantities currently recorded?
- [ ] Paper records
- [ ] Spreadsheet
- [ ] Existing computer system
- [ ] No organized record

**Sample answer:** Paper records and spreadsheets

### Q3. How difficult is it to find a product and check its available quantity?
- [ ] Very easy
- [ ] Easy
- [ ] Moderate
- [ ] Difficult
- [ ] Very difficult

**Sample answer:** Difficult

### Q4. What problems happen most often? (Select all that apply)
- [ ] Incorrect or outdated stock quantities
- [ ] Difficulty finding products
- [ ] Errors in prices or calculations
- [ ] Missing sales records
- [ ] Slow report preparation
- [ ] Other: ____________________

**Sample answer:** Incorrect stock quantities and difficulty finding products

### Q5. How are daily sales usually recorded?
- [ ] In a paper notebook
- [ ] In a spreadsheet
- [ ] In a computer system
- [ ] They are not recorded consistently

**Sample answer:** In a paper notebook

### Q6. How often do you need to check stock quantities?
- [ ] Several times a day
- [ ] Once a day
- [ ] Several times a week
- [ ] Only when a product is requested

**Sample answer:** Several times a day

---

## Screen 2 – Proposed System Features

**Purpose:** Identify which features users need in the proposed Mobile Shop Management System.

### Q7. Would you prefer one system for managing products, sales, and inventory?
- [ ] Yes
- [ ] No
- [ ] Not sure

**Sample answer:** Yes

### Q8. Which product information should the system display? (Select all that apply)
- [ ] Product name
- [ ] Model / category
- [ ] Selling price
- [ ] Available quantity
- [ ] Supplier information
- [ ] Product description

**Sample answer:** Product name, model, selling price, and available quantity

### Q9. Which features would be most useful? (Select up to three)
- [ ] Fast product search
- [ ] Recording sales
- [ ] Automatic stock updates
- [ ] Low-stock alerts
- [ ] Sales reports
- [ ] Inventory reports
- [ ] User accounts and permissions

**Sample answer:** Fast product search, automatic stock updates, and low-stock alerts

### Q10. How important are automatic stock updates after each sale?
- [ ] Very important
- [ ] Important
- [ ] Not important

**Sample answer:** Very important

### Q11. Which reports would you like the system to provide? (Select all that apply)
- [ ] Daily sales report
- [ ] Monthly sales report
- [ ] Current inventory report
- [ ] Low-stock products report
- [ ] Profit summary

**Sample answer:** Daily sales, monthly sales, and current inventory reports

### Q12. How easy should the system be to use?
- [ ] Very simple, with clear buttons and a few steps
- [ ] A detailed interface with more options
- [ ] No preference

**Sample answer:** Very simple, with clear buttons and a few steps

### Q13. Do different employees need different access permissions?
- [ ] Yes
- [ ] No
- [ ] Not sure

**Sample answer:** Yes

### Q14. What additional feature or improvement would you suggest?
**Sample answer:** A warning should appear when a product quantity becomes low.

## 3. Sample Response Summary (Illustrative Only)

The following is an example of how collected answers can be summarized. It is not real survey data.

## 4. How to Collect Real Answers

1. Share the questionnaire with people who are relevant to the shop.
2. Ask each participant to answer the questions based on their real experience.
3. Record the number of completed responses.
4. Replace the illustrative sample answers with the actual responses.
5. Summarize the results without including personal information unless participants consent.

## 5. Conclusion

This questionnaire is designed to collect user needs about the current shop operations and the expected features of the Mobile Shop Management System. The answers can help the project team prioritize product management, sales processing, inventory updates, reports, usability, and user permissions.

**Important:** The sample answers in this document demonstrate the expected answer format only. They must not be reported as real questionnaire results.
